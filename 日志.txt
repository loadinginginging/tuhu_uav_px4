  修改前：
  constexpr TI CONTENT_OUTPUT_DIM = product(typename SPEC::CONTENT::OUTPUT_SHAPE{});

  修改后：
  [[maybe_unused]] constexpr TI CONTENT_OUTPUT_DIM = product(typename SPEC::CONTENT::OUTPUT_SHAPE{});

  warning-as-error。

  修改位置：reset() 函数签名附近（约第 88 行）

  修改前：
  RL_TOOLS_FUNCTION_PLACEMENT void reset(DEVICE& device, const nn::layers::gru::LayerForward<SPEC>& layer,
  nn::layers::gru::State<STATE_SPEC>& state, RNG&, Mode<MODE> mode = Mode<mode::Default<>>{}) {

  修改后：
  RL_TOOLS_FUNCTION_PLACEMENT void reset(DEVICE& device, const nn::layers::gru::LayerForward<SPEC>& layer,
  nn::layers::gru::State<STATE_SPEC>& state, RNG&, [[maybe_unused]] Mode<MODE> mode =
  Mode<mode::Default<>>{}) {

  修改原因：
  在 MODE = rl_tools::mode::Default<> 的模板实例化下，if constexpr(mode::is<MODE,
  mode::sequential::ResetMask>) 分支会被编译期裁剪，导致参数 mode 在该实例中未被使用，触发 -Wunused-but-set-
  parameter，并因 -Werror 导致编译失败。保留参数名 mode 是为了兼容 ResetMask 分支中的 mode.mask 访问，添加
  [[maybe_unused]] 可以同时消除未使用参数告警。

  修改文件：~/src/lib/rl_tools/rl_tools/include/rl_tools/persist/backends/tar/operations_generic.h

  修改位置：dim_helper_read() 函数内（约第 193 行）

  修改前：
  char key[] = "dim_0";
  key[4] = '0' + DIM;
  if constexpr(DIM < SPEC::SHAPE::LENGTH){

  修改后：
  if constexpr(DIM < SPEC::SHAPE::LENGTH){
      char key[] = "dim_0";
      key[4] = '0' + DIM;

  修改原因：
  在模板递归终止分支 DIM == SPEC::SHAPE::LENGTH 下，if constexpr 会直接进入 else 分支返回 true，导致 key 在
  该实例中被赋值但未使用，触发 -Wunused-but-set-variable，并因 -Werror 导致编译失败。将 key 的定义与赋值移入
  有效分支即可消除该告警且不改变逻辑。

  修改后：

  修改原因：
  在模板递归终止分支 DIM == SPEC::SHAPE::LENGTH 下，if constexpr 会直接进入 else 分支返回 true，导致参数

  递归调用不变，给 metadata 添加 [[maybe_unused]] 消除告警。
